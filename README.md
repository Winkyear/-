# 数据分析项目集

本仓库收录两个可复现的数据分析项目，分别覆盖电商订单分析和游戏用户行为分析。每个项目都保留了 Python 清洗与分析脚本、SQL 查询、Power BI 指标说明、业务报告和可查看的 Excel/PPT 成果。

## 项目一：Olist 电商订单与支付分析

用订单、商品、支付、评价、客户和卖家数据分析经营规模、配送体验、支付方式和再次购买情况。项目覆盖 96,211 笔已送达订单与 93,104 名客户，并比较了准时与晚到订单的评价差异。

进入 [项目目录](./olist_ecommerce_finance_report) 查看分析过程、SQL、看板和汇报材料。

## 项目二：Steam 用户行为与内容分析

用 Steam 用户与游戏行为数据区分“拥有游戏”和“实际玩过游戏”，找出可做用户召回的对象和可作为推荐候选的内容。项目覆盖 12,393 名用户、5,153 个游戏和 70,474 条实际游玩记录。

进入 [项目目录](./steam_user_behavior_portfolio) 查看分析过程、SQL、看板和汇报材料。

## 技术栈

Python（Pandas、NumPy、Matplotlib）、SQL（SQLite / MySQL 语法）、Excel、Power BI、Anaconda。

## 数据说明

两个项目均基于公开数据集完成。为方便浏览和复现，仓库不包含原始数据、清洗中间表或本地数据库文件；每个项目的 README 中保留了数据来源、运行方式和口径说明。
