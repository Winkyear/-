# 数据来源与完整性

## 主数据：Steam 用户行为

- 和鲸数据集：包含用户行为的 Steam 游戏数据集
- 和鲸页面：https://www.heywhale.com/mw/dataset/5da18725037db3002d4468b3
- 和鲸文件名：`steam-200k.csv`
- 和鲸标注大小：8,958,107 字节
- 本地文件：`data/raw/steam_200k.csv`
- 本地 SHA-256：`2464A568E9B6B007D13D34E2E3A6C8DE00E5E7443F4913155F365AAA328C2874`
- 获取说明：和鲸下载接口需要登录。本项目从 GitHub 同名公开镜像获取文件，并用和鲸标注的文件大小进行核对。

字段为：用户 ID、游戏名、行为类型、行为值、常量辅助列。行为类型只有 `purchase` 和 `play`。`purchase` 的值为 1，`play` 的值为累计游玩小时。

## 补充数据：Steam 商店游戏元数据

- 和鲸数据集：Steam 商店游戏数据集
- 和鲸页面：https://www.heywhale.com/mw/dataset/647acaea5b5b58e99a85e74f
- 和鲸文件名：`steam.csv`
- 和鲸标注大小：5,815,053 字节
- 本地文件：`data/raw/steam_store.csv`
- 本地 SHA-256：`783087562C9BAB27FAF7C4C1C8040269489AB2FC2054549971BE01EB6C007F99`
- 原始采集：Nik Davis 基于 Steam Store 与 SteamSpy API 整理，数据快照约为 2019 年 5 月。

## 使用限制

1. 用户行为表没有事件时间，因此不能计算 DAU、留存、流失或活动前后效果。
2. `purchase` 表示拥有记录，不含订单金额、退款和购买日期，因此不能推导收入、付费率或 LTV。
3. 商店价格是快照值，不能解释历史购买决策。
4. 两表只按标准化游戏名精确匹配，不做模糊匹配，避免把同名或相近名称错误合并。
5. 所有结论均为横截面行为描述或关联性候选，不使用因果措辞。
